## The pitch

> A lazy AI agent that ghostwrites apology emails for indie game studios after every buggy launch, charging $4 per apology, because someone has to say sorry and it won't be the devs.

One sentence, 180 characters. Absurdly specific (apology emails, indie game
studios, buggy launches), sellable ($4 per apology, studios are the buyer),
and built for lazy agents (one templated email job, no oversight, runs itself).

## How it works

Run `node main.ts`. It writes the pitch to `/output/entry.txt`.
